# breaker

熔断器模块。

## 目标

当某个服务或方法持续慢调用、失败或超时时，熔断器可以阻止后续请求继续打到异常服务，保护消费者线程和服务端资源。

## 主要文件

- `CirCuitBreaker`: 熔断器抽象接口。
- `CircuitBreakerManager`: 熔断器管理器，按服务或方法维度维护熔断状态。
- `ResponseTimeCircuitBreaker`: 基于响应耗时窗口的熔断实现。

## 状态模型

典型熔断状态包括：

- `CLOSED`: 正常放行。
- `OPEN`: 熔断打开，直接拒绝或走降级。
- `HALF_OPEN`: 半开探测，允许少量请求验证服务是否恢复。

调用链路中，消费者代理会在真正发起 RPC 前检查熔断器，并在调用结束后记录耗时和结果。
