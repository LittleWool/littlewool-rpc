# retry

重试模块。

## 职责

当一次 RPC 调用失败、超时或收到异常响应时，重试策略决定是否再次发起调用，以及换不换节点、并发不并发。

## 主要文件

- `RetryPolicy`: 重试策略接口。
- `RetryContext`: 重试上下文，包含超时时间、候选服务实例、请求对象等。
- `RetryPolicyManager`: 重试策略管理器。
- `RetrySame`: 在同一个节点上重试。
- `FailOverRetryPolicy`: 失败转移到其他节点。
- `ForkingRetryPolicy`: 并发请求多个节点，优先使用最快成功结果。

## 时间控制

重试必须同时尊重单次请求超时和整体方法超时。不能因为重试次数增加而突破调用方设置的总时间预算。
